---
title: "Api key permissions unavailable"
description: "What the `api_key_permissions_unavailable` error means and what to do next."
---

The API, CLI and MCP return `api_key_permissions_unavailable` with HTTP 503. Repeating the same request unchanged does not help.

## What to do

Report the platform user-key permission configuration through feedback with this request_id; it affects every token the same way, whatever the integration. Repeated login does not fix it. After the platform confirms the fix, repeat the same create with the same name and Idempotency-Key.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
