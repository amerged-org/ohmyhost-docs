---
title: "Database schedule limit"
description: "What the `database_schedule_limit` error means and what to do next."
---

The API, CLI and MCP return `database_schedule_limit` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

List the project's database schedules for this environment and delete one you no longer need, then set the schedule again.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
