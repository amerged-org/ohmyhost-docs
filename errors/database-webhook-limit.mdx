---
title: "Database webhook limit"
description: "What the `database_webhook_limit` error means and what to do next."
---

The API, CLI and MCP return `database_webhook_limit` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

List the project's database webhooks for this environment and delete one you no longer need, then create the webhook again.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
