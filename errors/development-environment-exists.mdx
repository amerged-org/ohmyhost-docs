---
title: "Development environment exists"
description: "What the `development_environment_exists` error means and what to do next."
---

The API, CLI and MCP return `development_environment_exists` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Read project status and use the existing Dev environment ID.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
