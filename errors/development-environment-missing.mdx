---
title: "Development environment missing"
description: "What the `development_environment_missing` error means and what to do next."
---

The API, CLI and MCP return `development_environment_missing` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Select environment prod, or add Dev with 'ohmyhost project dev add'.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
