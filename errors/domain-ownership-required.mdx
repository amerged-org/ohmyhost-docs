---
title: "Domain ownership required"
description: "What the `domain_ownership_required` error means and what to do next."
---

The API, CLI and MCP return `domain_ownership_required` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

This hostname is not verified for this project yet. Add the _omh-project.HOST TXT record that ohmyhost domain paid status --project ULID --json shows for it, then apply again with ohmyhost domain paid apply --project ULID --hostname HOST --idempotency-key KEY --json. Repeating before the record is published cannot work.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
