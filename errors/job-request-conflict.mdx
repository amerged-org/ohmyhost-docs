---
title: "Job request conflict"
description: "What the `job_request_conflict` error means and what to do next."
---

The API, CLI and MCP return `job_request_conflict` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Read the job version and create a fresh quote before starting.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
