---
title: "Project rename blocked"
description: "What the `project_rename_blocked` error means and what to do next."
---

The API, CLI and MCP return `project_rename_blocked` with HTTP 409. Repeating the same request, with the same idempotency key, after a wait can succeed.

## What to do

Read project status and finish or retry any pending Native Auth deployment or other operation. Once preparation is complete, read the project again and rename with its current ETag.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
