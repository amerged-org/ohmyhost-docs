---
title: "Reconciliation required"
description: "What the `reconciliation_required` error means and what to do next."
---

The API, CLI and MCP return `reconciliation_required` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Read the original operation’s recovery facts before making one reconciliation attempt.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
