---
title: "Source generation conflict"
description: "What the `source_generation_conflict` error means and what to do next."
---

The API, CLI and MCP return `source_generation_conflict` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Read the project's current source and generation, reconcile any source switch, then prepare a new request.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
