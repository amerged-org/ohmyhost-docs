---
title: "Source scope unavailable"
description: "What the `source_scope_unavailable` error means and what to do next."
---

The API, CLI and MCP return `source_scope_unavailable` with HTTP 404. Repeating the same request unchanged does not help.

## What to do

Check the selected account, workspace, project and client permissions.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
