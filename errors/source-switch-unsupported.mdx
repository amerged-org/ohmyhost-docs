---
title: "Source switch unsupported"
description: "What the `source_switch_unsupported` error means and what to do next."
---

The API, CLI and MCP return `source_switch_unsupported` with HTTP 409. Repeating the same request unchanged does not help.

## What to do

Read the project's current source. Continue saving managed versions on this project, or have the owner approve a separate GitHub-backed project if GitHub source is required.

If the steps above do not resolve it, [report it](/feedback) with the `request_id` from the error.
