Paste this prompt into Codex, Claude Code, Cursor, Hermes or OpenClaw:

> Read https://ohmyho.st/llms.txt and https://ohmyho.st/skills/ohmyhost-get-started/SKILL.md. Connect this agent to ohmyho.st and use only the capabilities this app needs. Keep its saved source binding. For an unbound checkout, save the current files as managed source unless I ask for GitHub. Follow the deployment Skill and show me the verified live preview. Publish when I ask.

Your agent tells you what it needs, connects the intended account, reuses your workspace and inspects the selected app before creating anything. An agent with a shell can sign in with one browser link and one code, including from a Linux container. A connected chat without a shell uses managed OAuth. Unattended automation uses a private [API token](/login-tokens). Signing up is open. [Sources and versions](/sources) work across chats without creating another app.

Anyone can read both repositories to trace a stalled build, deployment or database change. Your application source stays in your project. The [ohmyho.st platform source](https://github.com/amerged-org/ohmyhost) uses Elastic License 2.0. Its [PostgreSQL infrastructure, PGCF](https://github.com/amerged-org/cloudflare-postgres), uses Apache-2.0.

## Start with what your app needs

A public Vite app can start with hosting alone. Add Postgres, [files](/files), runtime secrets or [functions and crons](/functions) when the application needs them. Transactional email needs Paid; a custom domain needs Paid or the opt-in [ohmyho.st flag](/domains). Keep your application's own authentication provider.

## Your first result

After the first save, the agent opens the [live preview](/previews) and shares it when ready. The deployed Dev site is available on Paid. Ask for its reusable share link if you need it. Publish to Prod when you are ready to open the live site.

- [First deployment](/quickstart): managed source and GitHub workflows.
- [Connect MCP](/agents/mcp): setup for your agent.
- [CLI](/cli): install and run the commands yourself.
- [API](/api): use your account token from another tool.

## Come back with a question

“Which project used the most credits?” “Is my domain ready?” “Export my database.” Your agent reads the saved [project context](/project-context) and uses the same account access as the [portal](https://app.ohmyho.st/).
