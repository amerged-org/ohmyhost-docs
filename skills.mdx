Install the entry Skill from the public repository:

```sh
npx skills add amerged-org/ohmyhost-docs -s ohmyhost-get-started
```

## Start with the get-started Skill

[`ohmyhost-get-started`](https://ohmyho.st/skills/ohmyhost-get-started/SKILL.md) is the entry point. It teaches your agent to:

- **Desktop, cloud shell or container.** Reuse the saved login or sign in through one browser link and confirmation code. MCP registration is optional.
- **Connected chat without a shell.** Use managed OAuth and verify the account with `identity_get`.
- **Unattended automation.** Load a private `OHMYHOST_TOKEN` in the process environment and verify its workspace. [Login and API tokens](/login-tokens).

Once the account and workspace are verified, the router hands off to the matching Skill. For deployment, the agent keeps the saved source binding and opens [Live Preview](/previews) after the first deployment.

Every step ends with a command that proves it, so a saved configuration or a closed browser tab is never mistaken for a working connection. Read the file yourself if you want the exact wording; it is the same text your agent follows.

Use another name from the catalogue for a specific task. The CLI packages and Skills do not require access to the private platform repository. Current product MCP servers also expose these instructions through their resources.
