
Requires Node.js 22 or newer.

```sh
npm install --global https://ohmyho.st/releases/0.1.30/ohmyhost-product-cli-0.1.30.tgz https://ohmyho.st/releases/0.1.30/ohmyhost-mcp-0.1.30.tgz
export OHMYHOST_ENVIRONMENT=production
ohmyhost login --json
ohmyhost whoami --json
```

The same release is on npm as `@amerged/ohmyhost-cli` and `@amerged/ohmyhost-mcp`. Both sources install the `ohmyhost` and `ohmyhost-mcp` commands, so keep one source per computer and upgrade from the one already installed (`npm ls --global` names it). To switch, first remove the other pair: `npm uninstall --global @ohmyhost/product-cli @ohmyhost/mcp` for the archives, `npm uninstall --global @amerged/ohmyhost-cli @amerged/ohmyhost-mcp` for npm.
